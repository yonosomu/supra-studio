# Проверки подготовленной сборки

Перед упаковкой выполнены:

- Четыре проверки стандартным `unittest`: наличие сборщика; очистка GLB с сохранением бинарных данных и атрибуции; отсутствие старого сборщика и дубликата модели; побайтное совпадение пересобранного HTML с готовым `index.html`.
- Все шесть браузерных наборов из `npm test`: диапазоны передач, записанный звук, эффект турбины и пауза, диски, дорога/колёса, полная функциональная регрессия. Страницы открывались через `file://` при отключённой сети.
- Проверка повторной сборки: результат побайтно совпал с включённым `index.html`.
- Проверка исходников, документации и декодированной модели на типичные секреты и локальные личные пути. Совпадений с пользовательскими секретами не обнаружено; метаданные плагинов удалены.
- Проверка иллюстрации `preview.png`: автомобиль и интерфейс отображаются без ошибки запуска.

Это результаты локальных проверок данной сборки, не гарантия отсутствия любой уязвимости. Публичный GitHub Actions/CI не запускался; удалённый репозиторий не создавался и не изменялся. После добавления собственных файлов проверки нужно повторить.
